Sheet 1 — Research Question & System Architecture

Question

How do sparse probe penetration (1–10%), arterial corridor selection bias (4:1), GPS multipath outliers, Markovian burst dropouts, and telemetry latency (τd ∈ {0, 30, 60} s) degrade MFD estimation and perimeter gating — layer by layer?

Hypotheses (Pre-Registered)

H1: Stateful anchor-preserving gating removes spike-induced cascade rejections. H2: Stratified Horvitz–Thompson removes 4:1 corridor accumulation bias. H3: PC-AKF covariance inflation preserves positive-definiteness under sensor blackout. H4: Smith residual correction compensates τd actuation latency.

Pipeline

  1. SUMO two-reservoir replay / Amsterdam urban traffic benchmark
  2. Probe telemetry (bias + noise + spikes + dropouts)
  3. Stateful kinematic quality gate
  4. Stratified HT Edie estimator
  5. Hysteresis PC-AKF
  6. Residual-corrected Smith-PI controller
  7. Schema-validated artifacts + IEEE report

Hysteresis branch

Unloading branch engages when N̂t < N̂t−1 and N̂t > 0.8 Ncrit, with Mmax,unload = 0.82 · Mmax,load.

Smith-PI residual

Normalized error et = (Neff − Ncrit) / Ncrit; forward rollout over the actuation ring buffer; residual δt−d = N̂AKF(t−d) − Nmodel(t−d). At d = 0 it reduces exactly to normalized PI.
